# 點心和燒烤類成分識別實現文檔

## 概述

本文檔說明點心類（餃子、小籠包、燒賣、春捲）和燒烤類料理的成分識別實現。

## 實現的功能

### 1. 點心類成分識別 (DishType.DUMPLING)

#### 支持的點心類型
- **餃子** (Dumplings)
  - 水餃、煎餃、蒸餃
  - 識別外皮和內餡（豬肉、高麗菜、韭菜等）
  - 區分不同地域變化（中式、台式）

- **小籠包** (Xiaolongbao)
  - 識別外皮、肉餡、湯汁（高湯凍）
  - 特別處理湯汁成分
  - 支持蟹黃小籠包等變化

- **燒賣** (Shumai)
  - 識別外皮、肉餡、蝦仁
  - 識別頂部裝飾（魚卵、蟹黃、青豆）
  - 支持港式和廣式變化

- **春捲** (Spring Roll)
  - 區分炸春捲和生春捲
  - 識別內餡（豬肉絲、高麗菜絲、冬粉等）
  - 支持台式潤餅和越南春捲

#### 核心特性

##### 1. 內餡識別
點心的內餡通常無法直接看到，系統會：
- 根據點心類型推測常見內餡
- 使用知識庫補充可能的成分
- 根據視覺線索（如透明度、顏色）推測內容

##### 2. 外皮和內餡比例調整
```typescript
// 典型比例
外皮: 30-40%
內餡: 50-60%
湯汁/調味料: 5-15%
```

系統會自動調整成分份量以符合這些比例。

##### 3. 特殊成分處理
- **小籠包湯汁**：識別高湯凍成分，標記為 `dumplingPart: 'soup'`
- **燒賣裝飾**：識別頂部的魚卵、蟹黃等裝飾
- **春捲類型**：區分油炸和非油炸，調整營養計算

##### 4. 份量估計
- 以**單個點心**為單位
- 典型範圍：30-120g
- 根據點心類型調整（小籠包較小，春捲較大）

#### 驗證規則

系統會檢查：
1. ✅ 是否有外皮成分
2. ✅ 是否有內餡成分（蛋白質或蔬菜）
3. ✅ 外皮和內餡比例是否合理（外皮應佔 25-45%）
4. ✅ 總份量是否合理（20-150g）
5. ✅ 烹飪方式是否正確（蒸、煮、炸）

### 2. 燒烤類成分識別 (DishType.BARBECUE)

#### 支持的燒烤類型
- **韓式烤肉** (Korean BBQ)
  - 識別肉類、生菜、泡菜、辣椒醬
  - 支持包肉吃法的配菜
  - 識別芝麻油等調味料

- **日式燒肉** (Japanese Yakiniku)
  - 注重肉質識別
  - 識別照燒醬、鹽燒等調味
  - 識別白蘿蔔泥等配菜

- **台式烤肉** (Taiwanese BBQ)
  - 識別多樣食材（吐司、米血糕、甜不辣）
  - 識別烤肉醬
  - 支持中秋節烤肉特色食材

- **中式燒烤** (Chinese BBQ)
  - 識別串燒類食材
  - 識別孜然等調味料
  - 識別烤羊肉串等特色

#### 核心特性

##### 1. 肉類識別
系統會識別：
- 肉類種類（豬、牛、雞、羊、海鮮）
- 肉的部位（五花肉、里肌肉、雞腿等）
- 肉的切法（片狀、塊狀、串燒）
- 烤製程度（生、半熟、全熟）

##### 2. 成分比例調整
```typescript
// 典型比例
肉類: 50-60%
蔬菜: 25-35%
醬料: 5-10%
其他配菜: 5-10%
```

##### 3. 烤製效果處理
- 考慮烤製過程的水分流失
- 調整營養計算（烤製會流失部分油脂）
- 識別焦化程度

##### 4. 地域特色識別
- **韓式**：生菜包肉、泡菜、辣椒醬、芝麻油
- **日式**：照燒醬、白蘿蔔泥、注重肉質
- **台式**：吐司、米血糕、甜不辣、多樣食材
- **中式**：串燒、孜然、辣椒粉

#### 驗證規則

系統會檢查：
1. ✅ 是否有肉類或海鮮
2. ✅ 烹飪方式是否為烤製
3. ✅ 是否有蔬菜配菜
4. ✅ 肉類份量是否合理（應佔 40-70%）
5. ✅ 是否有醬料
6. ✅ 總份量是否合理（100-500g）

## 使用方式

### 基本使用

```typescript
import { ComponentDetectionEngine } from './services/ComponentDetectionEngine';
import { DishType } from './types/ComponentDetection';

const engine = new ComponentDetectionEngine('zh-TW');

// 識別餃子
const dumplingResult = await engine.detectComponents(
  imageBuffer,
  '餃子',
  DishType.DUMPLING
);

// 識別烤肉
const bbqResult = await engine.detectComponents(
  imageBuffer,
  '烤肉',
  DishType.BARBECUE
);
```

## 知識庫數據

### 點心類映射

系統包含以下點心的成分映射：

1. **餃子** - 餃子皮、豬肉餡、高麗菜、青蔥、薑末、蒜末
2. **燒賣** - 燒賣皮、豬肉餡、蝦仁、香菇、魚卵、青豆
3. **春捲** - 春捲皮、豬肉絲、高麗菜絲、紅蘿蔔絲、豆芽菜、香菇絲、冬粉
4. **小籠包** - 麵皮、豬肉餡、高湯凍、薑絲、黑醋
5. **烤肉** - 豬肉片、烤肉醬、青椒、洋蔥、香菇、玉米、蒜頭

### 地域變化

每種料理都包含地域變化數據：
- 中式餃子：韭菜、蝦仁
- 台式餃子：玉米
- 港式燒賣：蟹黃
- 廣式燒賣：馬蹄
- 台式春捲：花生粉、香菜
- 越南春捲：生菜、薄荷葉、米紙
- 韓式烤肉：生菜、泡菜、辣椒醬、芝麻油
- 日式燒肉：照燒醬、白蘿蔔泥
- 台式烤肉：吐司、米血糕、甜不辣

## Vision API Prompt

### 點心類 Prompt 重點

```
1. 外皮部分：
   - 外皮類型、厚度、質地
   - 估計外皮重量

2. 內餡成分（根據視覺線索推測）：
   - 主要蛋白質
   - 蔬菜類
   - 調味料
   - 特殊成分（湯汁、蟹黃等）

3. 烹飪方式：
   - 蒸、煮、炸、煎

4. 配料和調味料：
   - 沾醬、配菜、裝飾

5. 視覺特徵：
   - 形狀、大小、顏色、透明度
```

### 燒烤類 Prompt 重點

```
1. 主要肉類：
   - 肉類種類、部位、切法
   - 估計重量
   - 烤製程度

2. 蔬菜類：
   - 蔬菜種類、切法
   - 估計份量、烤製程度

3. 醬料和調味料：
   - 烤肉醬、醃料、沾醬、調味料
   - 估計用量

4. 配菜和包裹食材：
   - 生菜、泡菜、蒜片、辣椒

5. 其他食材：
   - 主食類、加工食品、海鮮類

6. 視覺特徵：
   - 顏色、焦化程度、醬料塗抹、排列方式
```

## 性能考量

### 處理時間
- 點心類：2-4 秒（內餡推測需要更多處理）
- 燒烤類：3-5 秒（多種食材識別）

### 準確率目標
- 外皮識別：> 95%
- 主要內餡識別：> 80%（因為無法直接看到）
- 肉類識別：> 90%
- 蔬菜識別：> 85%
- 份量估計誤差：< ±25%

## 已知限制

### 點心類
1. **內餡識別**：無法直接看到內餡，主要依賴知識庫推測
2. **湯汁估計**：小籠包的湯汁量難以從外觀判斷
3. **混合餡料**：複雜的混合餡料（如三鮮餡）難以完全識別

### 燒烤類
1. **烤製程度**：難以準確判斷肉的熟度
2. **醃料識別**：醃製在肉內的調味料無法識別
3. **份量估計**：烤製後的縮水程度難以精確計算
