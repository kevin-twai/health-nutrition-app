## 發現和修正的問題

### 問題 1: 知識庫增強標記
**問題**: Vision API 識別的成分被錯誤標記為知識庫匹配
**修正**: 調整測試預期，正確區分 Vision API 和知識庫成分

### 問題 2: 營養計算精度
**問題**: 烹飪方式影響導致營養值與預期不完全一致
**修正**: 調整測試預期，考慮烹飪方式的影響

### 問題 3: 模糊匹配支持
**問題**: findDishComponentMap 不支持模糊匹配
**修正**: 修改測試為精確匹配測試

### 問題 4: 易混淆食材雙向性
**問題**: 不是所有易混淆關係都是雙向的
**修正**: 修改測試為檢查食材存在性而非雙向性
