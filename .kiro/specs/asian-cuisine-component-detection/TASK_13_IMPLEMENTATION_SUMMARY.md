# Task 13: 地域變化支持實施摘要

## 概述

成功實施了任務 13「添加地域變化支持」，為亞洲料理成分識別系統添加了台灣、日本、韓國、中國和東南亞地區的特色料理和食材支持。

## 實施內容

### 13.1 台灣料理支持 ✅

#### 新增料理成分映射
1. **滷肉飯** (Braised Pork Rice)
   - 常見成分：白飯、滷肉、滷蛋、酸菜、青菜、滷汁
   - 地域變化：豆乾、筍乾
   - 典型份量：300-450g

2. **牛肉麵** (Beef Noodle Soup)
   - 常見成分：麵條、牛肉塊、牛肉湯、青菜、酸菜、青蔥、香菜、辣椒
   - 地域變化：牛筋、豆乾、番茄
   - 典型份量：600-850g

3. **蚵仔煎** (Oyster Omelette)
   - 常見成分：蚵仔、雞蛋、地瓜粉漿、小白菜、豆芽菜、甜辣醬
   - 地域變化：香菜
   - 典型份量：180-280g

4. **臭豆腐** (Stinky Tofu)
   - 常見成分：臭豆腐、泡菜、蒜泥、辣椒醬、醬油膏、香菜
   - 地域變化：九層塔
   - 典型份量：150-250g

5. **鹽酥雞** (Taiwanese Popcorn Chicken)
   - 常見成分：雞肉塊、地瓜粉、九層塔、蒜頭、辣椒、胡椒鹽
   - 地域變化：青蔥
   - 典型份量：120-200g

### 13.2 日式料理支持 ✅

#### 新增料理成分映射
1. **壽司** (Sushi)
   - 常見成分：壽司飯、生魚片、海苔、芥末、醬油、醃薑
   - 地域變化：玉子、小黃瓜、酪梨
   - 典型份量：60-100g (每貫)

2. **天婦羅** (Tempura)
   - 常見成分：蝦、天婦羅麵衣、茄子、南瓜、香菇、青椒、天婦羅醬、白蘿蔔泥
   - 地域變化：紫蘇葉
   - 典型份量：200-300g

3. **日式定食** (Japanese Set Meal)
   - 常見成分：白飯、味噌湯、烤魚、醃漬物、冷豆腐、煮物、沙拉
   - 地域變化：納豆、溫泉蛋
   - 典型份量：500-700g

### 13.3 韓式料理支持 ✅

#### 新增料理成分映射
1. **韓式烤肉** (Korean BBQ)
   - 常見成分：牛肉片、生菜、泡菜、蒜片、青辣椒、洋蔥、辣椒醬、芝麻油、白飯
   - 地域變化：芝麻葉、大醬、蔥沙拉
   - 典型份量：300-450g

2. **石鍋拌飯** (Bibimbap)
   - 常見成分：白飯、牛肉絲、煎蛋、菠菜、豆芽菜、紅蘿蔔絲、櫛瓜、香菇、泡菜、辣椒醬、芝麻油、芝麻
   - 地域變化：蕨菜、桔梗
   - 典型份量：450-650g

3. **泡菜鍋** (Kimchi Jjigae)
   - 常見成分：泡菜、豬肉片、豆腐、青蔥、洋蔥、蒜頭、辣椒粉、高湯
   - 地域變化：年糕、拉麵
   - 典型份量：500-700g

### 13.4 中式和東南亞料理支持 ✅

#### 新增中式料理成分映射
1. **麻婆豆腐** (Mapo Tofu)
   - 常見成分：豆腐、豬絞肉、豆瓣醬、花椒、辣椒、蒜末、薑末、青蔥、辣油
   - 地域變化：花椒粉
   - 典型份量：280-400g

2. **北京烤鴨** (Peking Duck)
   - 常見成分：烤鴨肉、鴨皮、荷葉餅、甜麵醬、青蔥絲、小黃瓜絲
   - 地域變化：白糖
   - 典型份量：180-280g

#### 新增東南亞料理成分映射

   - 地域變化：蘿蔔乾、豆腐乾
   - 典型份量：300-450g

   - 常見成分：河粉、牛肉片、牛骨湯、豆芽菜、羅勒、香菜、青蔥、檸檬、辣椒、魚露

## 技術實施細節

### 文件修改

1. **apps/api/src/data/dishComponentMaps.ts**
   - 新增 13 個料理成分映射
   - 涵蓋台灣、日本、韓國、中國、東南亞地區
   - 每個料理包含詳細的成分資訊、烹飪方式、營養影響和地域變化

2. **apps/api/src/data/componentInfoExtensions.ts**
   - 新增 50+ 個地域特色食材
   - 為每個食材定義類別、常見料理、烹飪方式和份量範圍
   - 支持成分識別系統的知識庫查詢

### 數據結構

每個料理映射包含：
- 料理名稱（中英文）
- 料理類型（DishType）
- 地區標籤
- 常見成分列表（含份量範圍、頻率、烹飪方式、營養影響）
- 地域變化（不同地區的特色成分）
- 典型份量範圍

每個食材擴展包含：
- 成分類別（ComponentCategory）
- 是否為常見成分
- 典型料理列表
- 烹飪方式列表
- 份量範圍（最小、最大、典型）
