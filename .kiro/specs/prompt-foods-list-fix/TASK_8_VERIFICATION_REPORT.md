## 關鍵改進點總結

### 1. 移除限制性語句 ✅
**修復前：**
> "foods 列表必須包含所有可見的食材。如果你在 description 或 overallDescription 中提到了某個食材，那麼該食材也必須出現在 foods 列表中"

**修復後：**
> "foods 列表是獨立的結構化數據，必須包含圖片中的所有食材。即使某個食材在 description 中未提及，只要在圖片中可見，就必須加入 foods 列表"

### 2. 添加識別步驟 ✅
所有 prompt 都包含清晰的步驟指南：
- 步驟 1：仔細觀察圖片
- 步驟 2：識別每一種食材
- 步驟 3：估算份量
- 步驟 4：撰寫描述

### 3. 添加完整性檢查清單 ✅
每個 prompt 都包含檢查清單，確保不遺漏食材：
- [ ] 已識別所有可見的主要食材
- [ ] 已識別所有可見的配菜
- [ ] 已識別所有可見的小配料
- [ ] 已識別調味料或醬汁
- [ ] foods 列表中至少有 3 種食材

### 4. 提供具體範例 ✅
每個 prompt 都包含完整的範例，展示如何識別多種食材：
- 味噌湯範例（湯底 + 豆腐 + 海帶芽 + 蔥花）
- 涼拌干絲範例（豆腐干絲 + 芹菜絲 + 胡蘿蔔絲 + 香菜 + 麻油）
- 炒豆干範例（豆干 + 糯米椒 + 蒜片 + 辣椒 + 蔥段 + 醬油 + 米酒）

### 5. 強調優先順序 ✅
明確將「識別所有食材」作為最優先任務：
> "你的首要任務是：仔細觀察圖片，識別並列出所有可見的食材到 foods 列表中"

### 6. 提供份量估算標準 ✅
為常見食材提供份量參考：
- 豆腐：每塊約 30-50g
- 蔬菜絲：每份約 20-30g
- 蔥花、香菜：約 5-10g
- 湯底：約 200-300ml
