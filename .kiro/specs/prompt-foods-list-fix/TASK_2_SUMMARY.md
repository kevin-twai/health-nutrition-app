# Task 2 實施總結：修改湯品識別模板

## 完成日期
2025-11-18

## 任務描述
修改 `createSoupPrompt()` 方法，強化湯品識別的完整性和準確性。

## 實施內容

### 1. 核心任務強調
- ✅ 在 prompt 開頭明確標示核心任務：「識別湯底和所有配料」
- ✅ 使用醒目的標題和格式強調重要性

### 2. 配料識別步驟（表面→中間→底部）
- ✅ **步驟 1**：識別湯底（類型、顏色、濃稠度、份量）
- ✅ **步驟 2**：按位置識別配料
  - 2.1 浮在表面的配料（蔥花、香菜、油、芝麻等）
  - 2.2 中間層的配料（豆腐、肉片、蔬菜、海鮮等）
  - 2.3 沉在底部的配料（海帶、麵條、丸子等）
- ✅ **步驟 3**：估算份量（提供詳細的份量參考表）
- ✅ **步驟 4**：完整性檢查（checklist 格式）

### 3. 具體配料範例
提供了 4 種常見湯品的完整配料範例：
- ✅ **味噌湯**：湯底 + 豆腐 + 海帶芽 + 蔥花 + 可能的其他配料
- ✅ **排骨湯**：湯底 + 排骨 + 白蘿蔔 + 薑片 + 蔥段 + 可能的其他配料
- ✅ **酸辣湯**：湯底 + 豆腐絲 + 木耳 + 筍絲 + 蛋花 + 香菜 + 可能的其他配料
- ✅ **蔬菜湯**：湯底 + 高麗菜 + 紅蘿蔔 + 玉米 + 香菇 + 可能的其他配料

### 4. 最小配料數量要求
- ✅ 明確要求：如果湯中有多種配料，foods 列表應至少包含 3-5 種配料（不含湯底）
- ✅ 提醒：如果只識別到 1-2 種配料，可能有遺漏，需要再仔細觀察

### 5. 份量估算參考標準
提供了詳細的份量估算表格：

| 食材類型 | 參考份量 |
|---------|---------|
| 湯底 | 200-300ml |
| 豆腐（每塊） | 30-50g |
| 海帶/海帶芽（每片） | 10-20g |
| 蔬菜（每份） | 30-50g |
| 肉片（每片） | 20-30g |
| 蔥花/香菜 | 5-10g |
| 丸子（每個） | 15-25g |
| 麵條（每份） | 80-120g |
| 米粉/粉絲（每份） | 50-80g |

### 6. 完整性檢查清單
添加了 checklist 格式的完整性檢查：
- ✅ 已識別湯底類型和份量
- ✅ 已識別浮在表面的所有配料
- ✅ 已識別中間層的所有配料
- ✅ 已識別沉在底部的所有配料
- ✅ foods 列表中至少有 3-5 種配料
- ✅ 每種配料都有合理的份量估算
- ✅ 沒有遺漏任何明顯可見的配料

### 7. 重要原則
明確了 5 個重要原則：
1. **必須識別湯底和所有配料**
2. **最小配料數量要求**（3-5 種）
3. **按位置識別配料**（表面→中間→底部）
4. **份量估算要準確**
5. **區分相似食材**（嫩豆腐 vs 板豆腐、海帶 vs 海帶芽等）

## 預期效果

### 修改前的問題
- AI 可能只識別湯品名稱（如"味噌湯"），而不列出具體配料
- 容易遺漏小配料（蔥花、香菜等）
- 容易遺漏沉在底部的配料（海帶、麵條等）
- 沒有明確的識別步驟和檢查清單

### 修改後的改善
- ✅ AI 會按照步驟逐層識別配料（表面→中間→底部）
- ✅ 提供了具體的配料範例，AI 知道應該識別哪些食材
- ✅ 明確要求最小配料數量（3-5 種），避免遺漏
- ✅ 提供了詳細的份量估算標準
- ✅ 有完整性檢查清單，確保不遺漏配料

## 測試建議

### 測試案例 1：味噌湯
- **輸入**：味噌湯圖片（包含豆腐、海帶芽、蔥花）
- **預期輸出**：
  ```json
  {
    "foods": [
      {"name": "味噌湯底", "portion": 250, "position": "湯底"},
      {"name": "豆腐", "portion": 30, "position": "中間"},
      {"name": "海帶芽", "portion": 10, "position": "沉在底部"},
      {"name": "蔥花", "portion": 5, "position": "浮在表面"}
    ],
    "totalIngredients": 4
  }
  ```

## 驗證指標

1. **配料識別完整度**
   - 目標：識別出至少 80% 的可見配料
   - 計算方式：(識別出的配料數 / 實際可見配料數) × 100%

2. **foods 列表長度**
   - 修改前：平均 1-2 種配料
   - 修改後：平均 3-5 種配料（複雜湯品）

3. **份量估算準確度**
   - 目標：份量估算誤差在 ±20% 以內
   - 驗證方式：與實際份量對比
