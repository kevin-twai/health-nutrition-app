## 快速開始

### 步驟 1: 拍攝或上傳照片

1. 打開應用程式
2. 點擊「拍照」或「上傳照片」按鈕
3. 拍攝您的食物或從相簿選擇照片
4. 確認照片清晰可見

### 步驟 2: 等待識別

系統會自動分析您的照片，通常需要 3-8 秒。您會看到：
- 🔍 正在分析圖片...
- ⏳ 識別中...
- ✅ 識別完成！

### 步驟 3: 查看結果

識別完成後，您會看到：
- 📋 識別出的所有食材
- 🍽️ 每種食材的份量
- 📊 營養資訊（熱量、蛋白質、碳水化合物、脂肪）
- 🎯 識別信心度

## 如何拍攝食物照片

### 拍照技巧

為了獲得最佳識別效果，請遵循以下建議：

#### ✅ 好的照片範例

1. **光線充足**
   - 使用自然光或明亮的室內燈光
   - 避免陰影遮擋食物
   - 不要逆光拍攝

2. **角度適當**
   - 從正上方或 45 度角拍攝
   - 確保所有食材都清晰可見
   - 不要太近或太遠

3. **背景簡潔**
   - 使用單色背景（白色、木紋桌面）
   - 避免雜亂的背景
   - 移除不相關的物品

4. **食物完整**
   - 確保所有食材都在畫面內
   - 不要切掉食物的一部分
   - 如果是多道菜，分開拍攝

#### ❌ 避免的情況

- 🚫 照片模糊不清
- 🚫 光線太暗或太亮
- 🚫 食物被遮擋
- 🚫 角度太斜
- 🚫 背景太雜亂
- 🚫 照片過度濾鏡處理

### 特殊料理拍攝建議

#### 涼拌菜
- 確保所有絲狀食材都清晰可見
- 拍攝前可以稍微撥開食材，展示不同層次
- 注意拍到醬汁和調味料

#### 湯品
- 拍攝時稍微攪拌，讓配料浮出水面
- 確保湯汁和固體食材都清晰可見
- 可以用湯匙舀起部分食材拍攝

#### 混合菜餚
- 盡量展示所有不同的食材
- 可以拍攝多張不同角度的照片
- 如果食材很多，可以分區域拍攝

## 理解識別結果

### 識別結果包含什麼？

#### 1. 食材列表

每個識別出的食材會顯示：

```
🥬 芹菜
   份量: 30克
   熱量: 5 kcal
   信心度: 92%
```

- **食材名稱**: 繁體中文名稱
- **份量**: 估算的重量或數量
- **營養資訊**: 該份量的營養成分
- **信心度**: 系統對識別結果的確定程度（0-100%）

#### 2. 料理資訊

```
🍽️ 料理類型: 台式
👨‍🍳 烹飪方式: 涼拌
📝 描述: 這是一道涼拌菜，包含豆腐干絲、芹菜絲和胡蘿蔔絲
```

#### 3. 總營養統計

```
📊 總計
   熱量: 180 kcal
   蛋白質: 12g
   碳水化合物: 15g
   脂肪: 8g
```

### 信心度說明

- **90-100%** 🟢 非常確定
  - 系統非常有信心識別正確
  - 視覺特徵非常明確

- **80-89%** 🟡 確定
  - 系統相當確定
  - 可能有少量不確定因素

- **70-79%** 🟠 較確定
  - 系統認為識別正確，但存在相似食材
  - 會提供替代選項供您選擇

- **60-69%** 🔴 不太確定
  - 系統不太確定
  - 強烈建議查看替代選項

- **< 60%** ⚠️ 不確定
  - 系統無法確定
  - 請查看替代選項或重新拍照

## 使用替代選項功能

### 什麼是替代選項？

當系統對某個食材的識別信心度較低時（通常低於 85%），會提供 2-3 個可能的替代選項，讓您選擇正確的食材。

### 如何使用替代選項

#### 步驟 1: 查看替代選項

當識別結果中出現替代選項時，您會看到：

```
🤔 系統識別為: 麵條 (信心度: 75%)

💡 可能的替代選項:
   1. 豆腐干絲 (信心度: 72%)
      理由: 形狀相似，但質地更粗糙，顏色偏黃
   
   2. 米粉 (信心度: 68%)
      理由: 細長條狀，但顏色更白
   
   3. 粉絲 (信心度: 65%)
      理由: 細長，但應該是透明的
```

#### 步驟 2: 選擇正確選項

1. 仔細查看每個選項的描述和理由
2. 對照您的實際食物
3. 點擊正確的選項

```
[ ] 麵條
[✓] 豆腐干絲  ← 選擇這個
[ ] 米粉
[ ] 粉絲
```

#### 步驟 3: 確認選擇

點擊「確認」按鈕，系統會：
- 更新識別結果
- 重新計算營養資訊
- 記錄您的選擇以改進未來識別

### 替代選項的判斷技巧

#### 豆腐干絲 vs 麵條

**豆腐干絲**:
- 顏色: 淡黃色或米白色
- 質地: 略粗糙，不光滑
- 特徵: 有豆製品特有的質感
- 常見於: 涼拌菜

**麵條**:
- 顏色: 較白或偏黃
- 質地: 光滑有光澤
- 特徵: 有彈性，表面光滑
- 常見於: 湯麵、炒麵

#### 米粉 vs 粉絲

**米粉**:
- 顏色: 純白色
- 粗細: 較粗（0.5-2mm）
- 特徵: 較脆，容易斷
- 常見於: 炒米粉、湯米粉

**粉絲**:
- 顏色: 透明或半透明
- 粗細: 極細（0.3-0.8mm）
- 特徵: 滑溜，煮熟後透明
- 常見於: 湯品、涼拌

#### 玉米筍 vs 筍子

**玉米筍**:
- 形狀: 細長圓柱形，整根均勻
- 大小: 長 5-8cm，直徑 0.8-1.5cm
- 特徵: 頂端有玉米鬚，整根可食用
- 常見於: 炒菜、火鍋

**筍子**:
- 形狀: 較粗，通常切片或切塊
- 大小: 較大，切片後 3-5cm
- 特徵: 有明顯的纖維紋理
- 常見於: 炒菜、湯品

#### 糯米椒 vs 青椒

**糯米椒**:
- 形狀: 細長形，略彎曲
- 大小: 長 8-12cm，直徑 1.5-2cm
- 特徵: 表面有皺褶，通常整根烹調
- 辣度: 微辣或不辣
- 常見於: 台式熱炒

**青椒**:
- 形狀: 方形或圓形，燈籠狀
- 大小: 長 8-12cm，寬 6-10cm
- 特徵: 表面光滑，肉厚，有空腔
- 辣度: 不辣
- 常見於: 炒菜、沙拉

### 什麼時候應該選擇替代選項？

✅ **應該選擇替代選項的情況**:
- 系統識別的食材明顯不對
- 您確定實際食材是什麼
- 替代選項中有正確答案

❌ **不需要選擇的情況**:
- 系統識別正確（即使信心度不是 100%）
- 您不確定哪個是正確的
- 所有選項都不對（這時請提供反饋）

## 如何提供反饋

您的反饋對我們非常重要！它幫助系統持續學習和改進。

### 為什麼要提供反饋？

- 🎯 提高識別準確度
- 🔧 幫助修正常見錯誤
- 📈 改善整體用戶體驗
- 🌟 讓系統更了解您的飲食習慣

### 提供反饋的方式

#### 方式 1: 快速反饋

在識別結果頁面，您會看到：

```
識別結果正確嗎？
[👍 正確]  [👎 不正確]
```

**點擊「正確」**:
- 系統會記錄這次成功的識別
- 幫助強化正確的識別模式

**點擊「不正確」**:
- 進入詳細反饋頁面
- 可以指出具體錯誤

#### 方式 2: 詳細反饋

點擊「不正確」後，您可以：

##### 1. 標記錯誤的食材

```
❌ 識別錯誤的食材:
   [ ] 麵條 → 實際是: 豆腐干絲
   [ ] 青椒 → 實際是: 糯米椒
```

##### 2. 添加遺漏的食材

```
➕ 遺漏的食材:
   [ ] 胡蘿蔔絲
   [ ] 麻油
   [ ] 蒜末
```

##### 3. 確認正確的食材

```
✅ 識別正確的食材:
   [✓] 芹菜
   [✓] 香菜
```

##### 4. 提供額外說明（選填）

```
💬 其他說明:
   這是涼拌豆腐干絲，醬汁是麻油和醬油...
```

#### 方式 3: 拍照反饋

如果識別結果差異很大，您可以：

1. 點擊「重新拍照」
2. 從不同角度拍攝
3. 確保光線和焦距更好
4. 提交新照片

### 反饋範例

#### 範例 1: 食材識別錯誤

**系統識別**:
- 麵條 100克

**實際情況**:
- 豆腐干絲 100克

**如何反饋**:
1. 點擊「不正確」
2. 選擇「麵條」
3. 在「實際是」欄位輸入「豆腐干絲」
4. 點擊「提交反饋」

#### 範例 2: 遺漏食材

**系統識別**:
- 豆腐干絲 50克
- 芹菜 30克

**實際情況**:
- 豆腐干絲 50克
- 芹菜 30克
- 胡蘿蔔絲 20克 ← 遺漏
- 麻油 1茶匙 ← 遺漏

**如何反饋**:
1. 點擊「不正確」
2. 確認「豆腐干絲」和「芹菜」正確
3. 在「添加遺漏食材」中輸入:
   - 胡蘿蔔絲
   - 麻油
4. 點擊「提交反饋」

#### 範例 3: 份量不準確

**系統識別**:
- 白飯 1碗 (200克)

**實際情況**:
- 白飯 半碗 (100克)

**如何反饋**:
1. 點擊食材旁的「調整份量」
2. 修改為正確份量
3. 點擊「確認」

### 反饋後會發生什麼？

1. **立即更新**: 您的識別結果會立即更新為正確資訊
2. **系統學習**: 系統會記錄這次反饋，用於改進未來識別
3. **感謝訊息**: 您會收到感謝訊息
4. **貢獻統計**: 您的反饋會計入貢獻統計

```
✅ 感謝您的反饋！

您的反饋已記錄，這將幫助我們改進識別準確度。

您已提供 15 次反饋
準確度改進: +2.3%
```

### 反饋最佳實踐

#### ✅ 好的反饋

- 具體指出錯誤的食材
- 提供正確的食材名稱
- 說明為什麼識別錯誤（選填）
- 及時提供反饋

#### ❌ 避免的情況

- 只說「不對」但不說明哪裡不對
- 提供模糊的食材名稱
- 在不確定的情況下提供反饋
- 重複提交相同的反饋

## 常見問題解答

### 關於識別功能

#### Q1: 系統可以識別哪些類型的食物？

**A**: 我們的系統專門優化了亞洲料理的識別，特別擅長：
- 中式料理（涼拌菜、熱炒、湯品等）
- 台式料理（小吃、熱炒、原住民料理）
- 日式料理（壽司、拉麵、定食）
- 韓式料理（泡菜、烤肉、湯品）
- 其他亞洲料理（泰式、越式等）

也支援西式料理，但準確度可能稍低。

#### Q2: 為什麼有時候識別需要較長時間？

**A**: 識別時間取決於：
- 圖片大小和複雜度
- 食材數量
- 識別階段（系統可能需要多次分析）

通常情況：
- 簡單食物：2-3 秒
- 複雜混合菜餚：5-8 秒
- 需要多次確認：8-10 秒

#### Q3: 信心度低於 80% 是否表示識別錯誤？

**A**: 不一定。信心度反映系統的確定程度，而非準確度。
- 信心度低可能是因為食材相似（如豆腐干絲 vs 麵條）
- 即使信心度 75%，識別仍可能正確
- 建議查看替代選項，對照實際食物判斷

#### Q4: 可以識別自製料理嗎？

**A**: 可以！系統會識別所有可見的食材，無論是：
- 餐廳料理
- 自製料理
- 外帶食物
- 便當

只要照片清晰，系統都能識別。

#### Q5: 系統能識別食物的新鮮度嗎？

**A**: 目前不能。系統只能識別：
- 食材種類
- 烹飪方式
- 大致份量
- 料理類型

無法判斷新鮮度、口味或品質。

### 關於替代選項

#### Q6: 什麼時候會出現替代選項？

**A**: 當系統的識別信心度低於 85% 時，會自動提供替代選項。這通常發生在：
- 食材相似（豆腐干絲 vs 麵條）
- 照片不夠清晰
- 食材被部分遮擋
- 少見的食材或料理

#### Q7: 如果所有替代選項都不對怎麼辦？

**A**: 您可以：
1. 點擊「都不對」按鈕
2. 手動輸入正確的食材名稱
3. 提交反饋
4. 或者重新拍照，從不同角度拍攝

#### Q8: 選擇替代選項後可以反悔嗎？

**A**: 可以！在確認之前，您可以：
- 重新選擇其他選項
- 點擊「取消」返回
- 點擊「重新識別」

確認後，您仍可以通過「編輯」功能修改。

### 關於反饋

#### Q9: 提供反饋是必須的嗎？

**A**: 不是必須的，但我們強烈建議：
- 當識別明顯錯誤時提供反饋
- 當遺漏重要食材時提供反饋
- 當份量差異很大時提供反饋

您的反饋幫助系統變得更好！

#### Q10: 反饋會立即改善識別嗎？

**A**: 反饋的效果分為：
- **立即效果**: 您當前的識別結果會立即更新
- **短期效果**: 系統會在幾小時內調整相關 prompt
- **長期效果**: 累積的反饋會用於定期優化系統

通常需要收集一定數量的反饋才能進行系統級改進。

#### Q11: 我的反饋會被其他人看到嗎？

**A**: 不會。您的反饋是：
- 匿名處理
- 僅用於系統改進
- 不會公開顯示
- 符合隱私保護政策

### 關於營養資訊

#### Q12: 營養資訊準確嗎？

**A**: 營養資訊基於：
- 標準食材營養數據庫
- 估算的份量
- 烹飪方式調整

準確度約 85-90%，但可能因為：
- 份量估算誤差
- 烹飪方式差異
- 食材品質不同

而有所偏差。建議作為參考，不要完全依賴。

#### Q13: 可以調整份量嗎？

**A**: 可以！點擊任何食材旁的「調整份量」按鈕：
1. 輸入實際份量
2. 選擇單位（克、碗、片等）
3. 系統會自動重新計算營養資訊

#### Q14: 為什麼有些食材沒有完整的營養資訊？

**A**: 可能原因：
- 調味料用量很少（如鹽、醬油）
- 特殊或少見的食材
- 資料庫中缺少該食材

我們持續更新營養資料庫，歡迎提供反饋。

### 技術問題

#### Q15: 支援哪些圖片格式？

**A**: 支援：
- JPEG / JPG
- PNG
- HEIC (iPhone 照片格式)

圖片大小限制：最大 10MB

#### Q16: 為什麼上傳失敗？

**A**: 可能原因：
- 圖片太大（超過 10MB）
- 圖片格式不支援
- 網路連接問題
- 伺服器暫時繁忙

解決方法：
- 壓縮圖片
- 轉換圖片格式
- 檢查網路連接
- 稍後重試

#### Q17: 可以離線使用嗎？

**A**: 目前不支援完全離線使用，因為：
- 需要連接 AI 識別服務
- 需要存取營養資料庫

但我們正在開發離線模式，敬請期待！

#### Q18: 識別記錄會保存多久？

**A**: 
- 識別結果：永久保存（除非您刪除）
- 原始照片：24 小時後自動刪除（隱私保護）
- 反饋記錄：永久保存（匿名）

您可以隨時在「歷史記錄」中查看過往識別。

## 提示和技巧

### 提高識別準確度的技巧

#### 1. 拍照技巧

✨ **最佳拍照時機**:
- 食物剛上桌，還沒開動
- 光線充足的時候
- 食材排列整齊時

✨ **拍照角度**:
- 正上方俯拍（最推薦）
- 45 度角斜拍
- 避免側面拍攝

✨ **多拍幾張**:
- 從不同角度拍攝
- 選擇最清晰的一張
- 如果食材很多，可以分區拍攝

#### 2. 處理複雜菜餚

🍜 **涼拌菜**:
- 稍微撥開食材，展示不同層次
- 確保所有絲狀食材都可見
- 拍攝醬汁和調味料

🍲 **湯品**:
- 攪拌後讓配料浮出
- 用湯匙舀起部分食材
- 拍攝湯汁和固體食材

🍱 **便當**:
- 分別拍攝每個格子
- 或者從正上方拍攝全景
- 確保所有食材都清晰

🔥 **熱炒**:
- 拍攝前稍微翻動
- 展示不同食材
- 注意拍到蒜片、辣椒等配料

#### 3. 特殊食材識別

🌾 **細絲狀食材**（豆腐干絲、麵條、米粉）:
- 近距離拍攝
- 注意拍出質地和顏色
- 可以用筷子夾起一些拍攝

🌶️ **相似蔬菜**（糯米椒、青椒）:
- 拍攝整體形狀
- 注意表面特徵（光滑 vs 皺褶）
- 拍攝切面（如果有）

🥬 **葉菜類**:
- 展開葉片
- 拍攝葉脈和形狀
- 注意顏色深淺

#### 4. 使用系統功能

📝 **添加備註**:
- 在識別後添加料理名稱
- 記錄特殊烹飪方式
- 標註餐廳或來源

🔖 **收藏常吃的食物**:
- 收藏常吃的料理
- 快速查看營養資訊
- 追蹤飲食習慣

📊 **查看歷史記錄**:
- 回顧過往飲食
- 分析營養攝取
- 發現飲食模式

### 常見識別挑戰及解決方法

#### 挑戰 1: 食材被醬汁覆蓋

**解決方法**:
- 拍照前稍微撥開醬汁
- 從側面拍攝，展示食材
- 在反饋中說明被覆蓋的食材

#### 挑戰 2: 食材切得很細碎

**解決方法**:
- 盡量近距離拍攝
- 使用手機的微距模式
- 在反饋中補充說明

#### 挑戰 3: 混合多種相似食材

**解決方法**:
- 分區域拍攝
- 用筷子分開不同食材
- 拍攝多張照片

#### 挑戰 4: 光線不足

**解決方法**:
- 移到光線充足的地方
- 使用手機閃光燈（但避免過曝）
- 調整手機曝光度

### 進階技巧

#### 🎯 批次識別

如果您有多道菜：
1. 分別拍攝每道菜
2. 依序上傳識別
3. 系統會自動累計總營養

#### 📱 使用快捷方式

- 長按應用圖示 → 快速拍照
- 使用語音輸入食材名稱
- 設定常用食材快捷鍵

#### 🔔 設定提醒

- 用餐時間提醒拍照
- 每日營養目標提醒
- 反饋貢獻提醒
