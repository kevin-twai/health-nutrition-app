# 生產環境部署檢查清單

在部署健康營養追蹤系統到生產環境之前，請確保完成以下所有項目。

## 部署前檢查

### 🔧 系統需求
- [ ] 伺服器規格符合最低需求 (4核心, 8GB RAM, 100GB SSD)
- [ ] Docker 20.10+ 已安裝
- [ ] Docker Compose 2.0+ 已安裝
- [ ] kubectl 已安裝 (如使用 Kubernetes)
- [ ] AWS CLI 已安裝並配置 (如使用 AWS 服務)

### 🔐 安全性配置
- [ ] 所有預設密碼已更改為強密碼
- [ ] JWT 秘密金鑰已設定 (至少 32 字元)
- [ ] SSL 憑證已準備並配置
- [ ] 防火牆規則已設定
- [ ] 資料庫存取權限已限制
- [ ] API Rate Limiting 已啟用

### 🌐 外部服務
- [ ] OpenAI API 金鑰已取得並測試
- [ ] Google Vision API 金鑰已取得並測試
- [ ] AWS S3 儲存桶已建立並配置
- [ ] Notion API 金鑰已設定 (如需要)
- [ ] Line API 金鑰已設定 (如需要)

### 📁 檔案準備
- [ ] `.env.production` 檔案已建立並填入所有必要變數
- [ ] SSL 憑證檔案已放入 `docker/nginx/ssl/` 目錄
- [ ] 備份目錄已建立並設定權限
- [ ] 日誌目錄已建立並設定權限

## 部署步驟

### Docker Compose 部署
- [ ] 執行 `make setup-prod` 設定生產環境
- [ ] 檢查 `.env.production` 檔案中的所有變數
- [ ] 執行 `make deploy-prod` 部署服務
- [ ] 執行 `make health-check` 驗證部署

### Kubernetes 部署
- [ ] 執行 `make secrets-create` 建立秘密
- [ ] 執行 `make deploy-k8s` 部署到 Kubernetes
- [ ] 執行 `make health-check` 驗證部署
